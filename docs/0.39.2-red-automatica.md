# 0.39.2: conexión automática y Drive al final

Juan autorizó el 2026-10-24 conservar el servicio de API de CurseForge en Cloud y aplicar
el resto del flujo: CurseForge → Modrinth → Drive, orígenes oficiales en una red normal,
puentes donde se detecten restricciones y espejo de Drive para Minecraft, Java y loaders.

## Referencia de interfaz

Se usa el diseño existente de Parabellum como referencia principal: pestañas de Explorar,
barra superior y asistente de CurseForge. Se conservan tipografía, colores, espaciado,
botones y estados de foco. Refero aporta `references/copywriting.md` (acciones claras y
explicaciones de recuperación) y `references/craft-details.md` (foco estable).
La conexión remota de Refero no dispone del identificador necesario en esta sesión.

| Decisión | Referencia | Motivo |
| --- | --- | --- |
| Retirar el interruptor de modo escuela | Pedido de Juan | La elección de ruta es automática. |
| Drive después de Modpacks | Pedido de Juan y pestañas actuales | Conservar acceso explícito al catálogo. |
| Una acción para abrir el portal | Asistente actual y guía de texto | El usuario elige el archivo; el launcher resuelve la conexión. |
| Conservar pendientes y huellas | Flujo 0.39.1 | No mezclar archivos distintos al usar un respaldo. |

## Contrato de red

- La API de CurseForge conserva el servicio actual y su clave fuera del cliente.
- La detección se hace por acceso a servicios, sin inferir el nombre de la escuela ni leer SSID.
- Una restricción requiere fallo directo reproducible y conectividad de control disponible.
- Sin internet, con autenticación rechazada, límites de peticiones o fallo del proveedor,
  no se activa un puente por asumir que se está en la escuela.
- Las decisiones caducan y se invalidan al volver a la ventana; se recupera la ruta directa.
- La prioridad de búsqueda no autoriza sustituir un modpack por otro ni perder overrides.
  Los archivos de otra fuente solo son equivalentes si coinciden sus huellas y tamaños.
